for "SHAP-Consistency-Guided Adversarial Training for Cross-Domain IoT Intrusion Detection: The XFCA Hybrid

Each folder has its own README with the exact commands. Every folder contains the code and the raw output of the
run reported in the manuscript.

## Data
The datasets are public and are not redistributed here. The scripts read the unmodified files below and check their
SHA-256 checksums (Table 24 of the manuscript). S1 and S2 download them automatically; for S3 and S4, place them in
a folder `data/` next to `code/`, or set the environment variable XFCA_DATA.
